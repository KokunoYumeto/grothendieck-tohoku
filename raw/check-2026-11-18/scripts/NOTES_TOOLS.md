## Regenerate the assembled notes

From the delivery root, run:

```bash
python -B scripts/assemble_notes.py --root . --supplement context-note-additions-interim-06
```

This writes `NOTES.md` and its item, paragraph, and comparison indexes. It does
not change the TeX, correction ledger, or check events. Four earlier English
search groups remain aliases of their French items. Four overlapping local
edits have explicit primary-bound paragraph ranges. Five proof-obligation
items have additional primary navigation links to already recorded checks.

The JSONL final inputs should be preserved before any deliberate regeneration
of earlier drafting stages. `add_proof_batch_*.py`,
`add_proof_batches_01_02.py`, and `author_proof_obligations.py` record the
original drafting sequence; the final assessments include later primary
revisions. The reviewed final JSONL, rather than a fresh run of those drafting
scripts, is the authoritative input to the assembled notes.

`prepare_note_context_inputs.py`, `prepare_supplementary_notes.py`,
`prepare_programme_notes.py`, and `select_math_note_context.py` preserve the
primary-assigned subjects, public references, programme proposals, and map
selections. These drafting helpers use a parent directory containing the
delivery named `TOHOKU_CHECK`; the map-selection helper also requires the
supplied context extracted under `input/context`. Those supplied attachments
are deliberately not copied into the delivery. The mathematical input helpers
prefer `CHECK_EVENTS.before-note-bindings.tsv` so the later background links
are not mistaken for additional mathematical-check notes.

## Check-event history

`normalize_check_events.py` records the primary normalization to the user's
six literal event types and the explicit refined-statement bindings. It
preserves the earlier table and refuses to overwrite that history.

`append_note_check_events.py` records the completed notes and the context
entries actually used. It adds only explicitly scoped background events; it
does not infer a proof, computation, or refutation from a note or a mapping
status. The script requires the actual recording time through `--utc` and
refuses to overwrite `CHECK_EVENTS.before-note-bindings.tsv`.

The current receipt is `NOTES_CHECK_EVENT_BINDING.json`. The mechanical
event-policy audit is `check-events-final-notes-interim-01`. Neither a passing
structural audit nor a context disposition certifies an unexamined proof.
